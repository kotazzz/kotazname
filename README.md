# kotazname

Сайт-визитка [kot_az](https://github.com/kotazzz): имя, аватар и ссылки на соцсети. Фон — дитер из [React Bits](https://reactbits.dev/backgrounds/dither). Языки: русский и английский.

## Запуск

Нужен Node.js.

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

Готовые файлы появятся в `dist`.
